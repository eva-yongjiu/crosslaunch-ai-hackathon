# 复赛现场演示脚本

建议时长：4 分钟。演示商品使用普通消费品，例如便携式桌面收纳盒；不要现场使用食品、保健品或复杂医疗宣称品类。

## 0:00—0:30 业务开场

“跨境卖家拿到一张供应商商品图后，要为不同平台重新制作图片、英文文案、详情页，还要避免未经证明的参数和宣称。上新无界把这个过程压缩为一个可追溯工作流。”

## 0:30—1:10 商品事实

创建一个真实商品项目，上传原图。点击“AI 识别原图”，展示商品类别、材质、结构等事实。将一条事实标记为已确认，说明未确认参数不会进入后续内容。

## 1:10—2:20 内容创作

进入 Amazon US，生成 Listing、详情页和五类商品图片。展示主图、场景图、模特图、对比图和尺寸图。切换 TikTok Shop US、Shopify US，展示同一商品事实下的不同平台输出。

## 2:20—3:10 合规闭环

打开合规中心，展示来源、规则版本、风险位置和修改建议。演示一条夸大宣称被拦截，点击修正，再次运行检测。说明图片也会经过视觉复检，未复检图片无法导出。

## 3:10—3:40 交付结果

下载 ZIP，打开真实图片、三平台 CSV/JSON、Shopify HTML、商品事实档案、合规报告和生成记录。

## 3:40—4:00 价值收束

“它的价值不是生成一段漂亮文案，而是把商品事实、内容生产、平台适配和发布前风险控制连接起来。现场耗时、内容数量和事实关联率均以本次真实运行结果为准。”

## 备用路径

演示前准备一个由真实 Token Plan 调用生成并已保存的演示项目。如果现场模型超时，先展示已完成项目，再现场执行商品事实识别和一个渠道生成，避免演示完全依赖一次临时生成。
