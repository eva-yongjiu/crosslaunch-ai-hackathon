# 复赛业务说明｜上新无界 CrossLaunch AI

## 1. 目标用户

中小跨境卖家、品牌出海团队和跨境代运营公司。它们通常只有供应商图片、零散商品资料和几个销售渠道，却需要分别准备图片、英文 Listing、详情页和平台合规材料。

## 2. 业务问题

- 同一个商品需要重复制作多套平台内容。
- 供应商资料不完整，AI 或人工容易补写未经证明的参数。
- 图片、标题、卖点和详情页之间容易出现商品不一致。
- 违规风险通常在发布后才暴露，返工成本高。

## 3. 产品闭环

```text
供应商图片/资料
      ↓
商品事实档案 + 人工确认
      ↓
图片矩阵 + 三平台 Listing + 详情页
      ↓
文字规则扫描 + 图片视觉复检
      ↓
修正/重新检测
      ↓
可交付上新 ZIP
```

## 4. 可量化价值

复赛现场只填写实际测量值：

| 指标 | 测量方法 | 实测结果 |
| --- | --- | --- |
| 单品上新耗时 | 从上传原图到下载 ZIP 计时 | 待实测 |
| 一次生成内容 | 图片类型、平台 Listing、详情模块数量 | 待实测 |
| 事实关联率 | 统计客观宣称是否关联已确认事实 | 待实测 |
| 高风险拦截率 | 构造夸大宣称后统计是否被检测 | 待实测 |
| 失败恢复 | 模型失败后是否保留任务和已保存版本 | 待实测 |

不要在答辩中把目标值说成已验证结果。演示时用屏幕录制或计时器展示真实结果。

## 5. 商业化路径

第一阶段以单品上新 SaaS 验证需求，按商品数、图片生成量或团队席位收费；第二阶段为代运营公司提供批量项目、品牌资产和审核协作；第三阶段再对接店铺 API，实现从内容生成到发布的闭环。

## 6. 技术差异化

本项目不是只把一句提示词发给模型，而是增加了三层约束：

1. 事实层：每条可见商品事实有来源、置信度和确认状态。
2. 生成层：图片和文案只能使用已确认事实，禁止自行补充参数。
3. 审核层：文字规则、图片视觉复检和规则来源一起进入导出门禁。

## 7. 风险边界

合规模块是风险筛查工具，不替代平台审核、检测认证或法律意见。没有对应专项规则包的品类只显示部分覆盖或需要人工审核。
